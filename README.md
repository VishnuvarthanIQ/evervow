# EverVow – Officiant & Ceremony Scripting Service

EverVow is a complete, premium-quality, multipurpose HTML website template for wedding officiants and ceremony scripting services. It helps couples discover wedding ceremony styles, book officiant consultations, customize ceremony scripts, schedule rehearsals, and manage their wedding ceremony through a dedicated couple dashboard.

## Features

- **Technologies**: HTML5, CSS3, Bootstrap 5, Tailwind CSS, Vanilla JavaScript.
- **No Frameworks**: Pure static template, easy to integrate with any backend or CMS.
- **Fully Responsive**: Mobile-first approach, tested on all major breakpoints.
- **Dark & Light Mode**: Built-in theme switcher with `localStorage` persistence.
- **RTL / LTR Support**: Toggle direction layout dynamically.
- **Interactive UI**: Dashboard interactions, service filters, script editor with text export, and more.
- **Premium Design**: Warm, romantic, elegant aesthetic with high-quality typography.

## Setup & Usage

1. **Clone or Download**: Simply download the project files.
2. **Open**: Since this is a static HTML template, no build process is required. You can simply open `index.html` in any web browser to view the template.
3. **Customization**: 
   - Colors and fonts can be tweaked in the Tailwind config script block in the `<head>` of the HTML files.
   - Core styling is found in `assets/css/style.css`.
   - Backend functionalities (like true authentication, database-driven bookings, and sending emails) will require integration with a server-side framework (e.g., Node.js, PHP, Python) or a backend-as-a-service. The provided interfaces are purely front-end demonstrations.
